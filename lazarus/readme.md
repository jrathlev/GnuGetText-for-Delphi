## GnuGetText adaptation for Lazarus

### Units
- **LazGetText:** GnuGetText translation system
- **LazLangUtils:** Additional utilities (Language initialization and switching)

### Example program:

The program **FileList** demonstrates the use of **LazLangUtils** and **LazGetText**:

- Integration of the units into your program
- Integration of mo files as resources instead of separate files
- Using a menu to switch languages
